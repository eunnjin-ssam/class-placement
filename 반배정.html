🎒 반 배정 도구

자동저장

① 학년 · 반 개수

새 학년의 학년명과 반 개수를 정해주세요.

② 반 이름 · 담임

각 반의 이름과 담임을 적어주세요. (담임은 비워도 됩니다)

③ 현재 반 명단

현재 같은 반인 학생들이 새로 배정될 반에 몰리지 않도록, 현재 반 이름을 등록해 두면 학생 입력 시 선택할 수 있습니다.

📋 엑셀 가져오기

1. 엑셀에서 전체 복사하여 붙여넣으면 등록됩니다.
2. 태그가 여러 개일 경우 쉼표(,)로 구분하세요.

🏷️ 태그 관리

같은 태그가 붙은 학생은 자동 배치에서 최대한 다른 반으로 흩어집니다.

학생 명단

성적·태도는 각 50점 만점, 총점 100점. 순위는 총점 기준입니다. 이름을 눌러 수정하세요.

순위이름성별 성적태도 총점현재반태그
학생이 없습니다. ‘엑셀 가져오기’ 또는 ‘학생추가’를 이용하세요.

반 배치

⚙️ 자동 배치를 누르면 성별·점수·태그 균형을 맞춰 배치되고, 다시 누를 때마다 다른 조합이 나옵니다.
이름표를 끌어 빈 자리에 놓으면 이동, 다른 학생 위에 놓으면 서로 교환됩니다. 🔒을 누른 학생은 자동 배치에서 제외(고정)됩니다.

미배치 학생

명렬표 인쇄

반별 명렬표를 미리보고 인쇄하거나 PDF로 저장합니다.

※ 한글용 파일은 .doc로 저장됩니다. 한글에서 열 때 문자코드는 ‘유니코드(UTF-8)’를 선택하세요. 연 뒤 다른 이름으로 저장 → 한글 문서(*.hwp)로 저장하면 됩니다.
