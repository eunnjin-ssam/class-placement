# 반 배정 도구 (Class Placement)

초등·중등 학급 반 배정을 돕는 단일 HTML 파일 도구입니다. 설치 없이 `반배정.html`을 브라우저로 열면 바로 사용할 수 있고, 모든 데이터는 **사용하는 브라우저에만 저장**되어 외부로 전송되지 않습니다.

## 주요 기능
- **환경설정**: 학년·반 개수(기본 2개), 반 이름·담임, 작년 반 명단 등록
- **학생 명단**: 엑셀/CSV 붙여넣기·입력 양식 다운로드·직접 입력, 점수(성적 50 + 태도 50 = 100점)·태그 관리, 점수/이름순 정렬, 명단 저장하기(CSV)
- **자동 반 배치**: 3단계 알고리즘
  1. 남·여 각각 점수순 스네이크(지그재그) 배분 → 성별 수·점수 동시 균등
  2. 같은 태그·작년 같은 반이 몰리면 같은 성별·비슷한 점수끼리 맞바꿔 분산
  3. 점수 미세조정으로 반별 총점 차 최소화
- **수동 조정**: 드래그앤드롭, 맞교환 모드, 고정(🔒), 되돌리기, 실시간 균형 지표·경고
- **명렬표**: 인쇄/PDF 저장, 한글(HWP)용(.doc) 내보내기, CSV 저장

## 사용법
1. `반배정.html`을 더블클릭해 브라우저로 엽니다.
2. ① 환경설정 → ② 학생 명단 입력 → ③ 반 배치(자동 후 수동 조정) → ④ 명렬표 인쇄 순으로 진행합니다.

## 기술 메모
- 외부 라이브러리·서버 없이 동작하는 단일 HTML 파일(바닐라 JS)
- 폰트는 Pretendard(온라인 시 CDN, 오프라인 시 설치 폰트로 대체)
- 데이터 저장: 브라우저 localStorage
